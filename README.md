# HR-attrition-analysis-dashboard
-Project Overview
This project analyzes employee attrition trends using Excel to identify key workforce retention insights. The dashboard evaluates attrition patterns across departments, age groups, education levels, and gender.

-Dataset
2,794 employee records
Includes demographic, job-related, and satisfaction metrics

-Key KPIs
Overall Attrition Rate: 17%
Attrition by Department
Attrition by Age Group
Attrition by Gender
Attrition by Job Role

-Tools Used
Microsoft Excel
Pivot Tables
Slicers
KPI Cards
Data Aggregation & Analysis

-Key Insights
Higher attrition observed among employees aged 25–34.
Sales department showed elevated attrition levels.
Male attrition rate was higher compared to female employees.

-Business Impact
The dashboard supports HR teams in identifying retention risks and improving workforce planning strategies.
